# 土豆服务器 · Potato Server Mod

适用于 **Minecraft 1.21.1 / Fabric / Java 21**，需要 Fabric API。

新增可食用物品「土豆服务器」：吃完后提示服务器被吃掉，随后冒烟、报警，显示 3、2、1 倒计时，并在约 5 秒后断开食用者的连接。服务器进程保持运行，玩家可以重新连接。

## 合成配方

在工作台使用 4 个铁锭、4 个红石粉和 1 个普通马铃薯，合成 1 个土豆服务器。拿到马铃薯后会解锁配方书条目。

| 铁锭 | 红石粉 | 铁锭 |
| --- | --- | --- |
| 红石粉 | 马铃薯 | 红石粉 |
| 铁锭 | 红石粉 | 铁锭 |

也可使用 `/give @s potato_server_mod:server_potato` 获取。

## 冷却与失明设置

- 每位玩家食用后有 **60 秒冷却**，从吃完时开始计算。冷却使用实际时间，同一次服务器运行期间退出重进不会重置；重启服务器后重置。
- 其他在线玩家默认获得约 5 秒失明，各玩家可以决定是否接收这一效果，普通玩家无需管理员权限。
- `/potatoserver blindness`：查看自己的设置。
- `/potatoserver blindness false`：关闭其他玩家食用时施加给自己的失明。
- `/potatoserver blindness true`：重新开启。
- 偏好按 UUID 保存在当前世界的 `data/potato_server_mod/blindness.properties`，退出重进或服务器重启后保留。该设置不关闭自己食用时的效果。

## 1.0.1

- 吃完后第 1 秒报警，第 2～4 秒显示 3、2、1，第 5 秒断开连接（100 个游戏 tick；服务器低 TPS 时演出会变慢）。
- 全程 3 次轻量报警、1 次爆炸音效，间隔约 1 秒。
- 每 4 tick 发一组烟雾和火焰，合计 49 个粒子包、265 个粒子，替代原先约 1.8 万个逐粒子发送的包。
- 用有明确结束时间的演出状态替代延迟任务队列。玩家退出、死亡或服务器停止时结束对应演出，不保留旧玩家对象。
- 不再通过反复发送玩家位置包模拟晃屏。
- 补充物品悬浮提示和合成配方。

## 开发与验证

执行 `bash ./gradlew build`。构建包含演出时长、音效/粒子预算、冷却边界和设置保存的回归检查。

提交后仍需在游戏内检查：合成与配方解锁、多人失明开关、5 秒断线、冷却期间物品不消耗，以及中途退出或死亡。
